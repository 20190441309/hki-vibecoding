## 1. 设计理念

### 品牌定位

> **"用 AI 加速开发，从想法到产品"**

这是一个融合**极客气质**与**创作者温度**的个人品牌网站，展示作者在 Vibe Coding 领域的探索、工具、项目和经验。

### 设计关键词

| 关键词 | 体现 |
| -------- | ------ |
| **极客 (Geek)** | Terminal 风格元素、网格背景、等宽字体、光标闪烁 |
| **温暖 (Warm)** | 现有陶土色（terracotta）+ 暖白 parchment 配色，保留 |
| **动感 (Dynamic)** | 滚动驱动动画、悬停反馈、平滑过渡 |
| **精致 (Polished)** | Awwwards 级微交互、磁力按钮、毛玻璃导航 |

### 色彩体系（保留现有配色，扩展暗色模式）

```css
/* 当前配色（保留） */
--bg-parchment: #f5f4ed;        /* 暖白背景 */
--bg-ivory: #faf9f5;            /* 象牙白 */
--accent-terracotta: #c96442;   /* 陶土红（主色） */
--accent-coral: #d97757;        /* 珊瑚色 */
--text-primary: #141413;        /* 近黑 */
--text-secondary: #5e5d59;      /* 次级灰 */

/* 新增暗色模式 */
--bg-dark: #1a1a18;             /* 暗色背景 */
--bg-dark-surface: #242320;     /* 暗色卡片 */
--text-on-dark: #b0aea5;        /* 暗色文字 */
```

## 4. 首页（/）

### 4.1 Hero 区域

**当前状态：** 纯文本标题 + 副标题 + 一个链接按钮，无动效。

**目标设计：**

```
┌──────────────────────────────────────────────┐
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │  ← 动态网格背景
│  ░░  ┌──────────────────────────────┐  ░░░  │
│  ░░  │  > _                         │  ░░░  │  ← 闪烁光标
│  ░░  │  > HKI's VibeCoding          │  ░░░  │  ← 打字机逐字出现
│  ░░  │  > 用 AI 加速开发            │  ░░░  │
│  ░░  │  > 从想法到产品 █            │  ░░░  │  ← 光标持续闪烁
│  ░░  └──────────────────────────────┘  ░░░  │
│  ░░      [ 探索作品 ]   [ 开始学习 ]     ░░░  │  ← 磁力悬停按钮
│  ░░                                    ░░░  │
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
└──────────────────────────────────────────────┘
         ↑ 滚动指示器 (向下滚动箭头，呼吸动画)
```

**动效清单：**

| 元素 | 动效 | 实现方式 |
| ------ | ------ | --------- |
| 网格背景 | 缓慢呼吸/脉冲动画 | CSS + framer-motion |
| Terminal 边框 | 边框发光渐变旋转 | CSS `@keyframes` |
| `>` 提示符 | 持续存在 | 静态字符 |
| 标题文字 | 打字机逐个出现 | framer-motion 字符拆分动画 |
| 光标 `█` | 持续闪烁 | CSS `@keyframes blink` |
| 副标题 | 文字渐入（Hero 标题打字完成后） | framer-motion opacity |
| CTA 按钮 | 磁力跟随（鼠标靠近时偏移） | GSAP quickTo |
| 滚动指示器 | 上下浮动 + 透明度脉冲 | framer-motion |
| 整体入场 | 页面加载时内容从下往上滑入 | framer-motion |

**交互逻辑：**

1. 页面加载 → 网格背景立即开始脉冲
2. 0ms → Terminal 边框渐显（500ms）
3. 500ms → 开始打字机效果：`> HKI's VibeCoding`（每个字 80ms）
4. 暂停 300ms → `> 用 AI 加速开发`（逐字）
5. 暂停 300ms → `> 从想法到产品`（逐字）
6. 打字完成后 → 光标持续闪烁
7. 按钮渐入（打字完成后 300ms）
8. 鼠标移近按钮 → 按钮跟随鼠标轻微偏移（磁力效果）
9. 滚动指示器持续呼吸

**组件改造：**

- 新建 `HeroTerminal` 组件替代现有 `Hero`
- Hero 区域高度：`100vh`

### 4.2 CardGrid（导航卡片区）

**当前状态：** 4 张静态卡片，CSS Grid 排列，无动效。

**目标设计：**

```
滚动到该区域时:
        ┌──────────┐    ┌──────────┐
        │ ⚡ 工作流  │    │ 🔧 工具链  │
        │ 从0到1...  │    │ Cursor...  │
        │ ────────→ │    │ ────────→ │
        └──────────┘    └──────────┘
        ┌──────────┐    ┌──────────┐
        │ 📝 心得   │    │ 📦 项目   │
        │ 避坑...   │    │ 用AI...   │
        │ ────────→ │    │ ────────→ │
        └──────────┘    └──────────┘
         ↑ 卡片依次从视口底部滑入
```

**动效清单：**

| 元素 | 动效 | 实现 |
| ------ | ------ | ------ |
| 卡片入场 | 从下方 60px 滑入 + 透明度 0→1 + 微旋转 -3°→0° | framer-motion `useInView` |
| 入场顺序 | 卡片 1 → 卡片 2 → 卡片 3 → 卡片 4，各延迟 0.1s | `transition.delay: i * 0.1` |
| 悬停 | 上浮 -8px + 阴影加深 + 边框发光 | framer-motion `whileHover` |
| 卡片内箭头 | 悬停时箭头右移 5px | CSS transition |
| 卡片图标 | 悬停时微旋转 10° | CSS transition |

**组件改造：**

- 现有 `CardGrid` + `Card` 组件，增加 framer-motion 动效
- 卡片改为 `'use client'`

```
│                                        │
│  ┌── 第 2 步：规划 ──────────────────┐ │  ← 每张卡片不同颜色左边框

│  └────────────────────────────────────┘ │
│                                        │
│  ┌── 第 4 步：提交 ──────────────────┐ │
│  │  ○ commit + PR                    │ │
│  └────────────────────────────────────┘ │
│                                        │
```

| 元素 | 动效 | 实现 |
| ------ | ------ | ------ |
| 页面标题 | 底部装饰线从中间向两边展开 | framer-motion `useInView` |

| 卡片编号 | 数字放大动画（0.8→1.2→1） | framer-motion spring |
| 正反例子 | 左右交错入场（坏例左入，好例右入） | framer-motion |
| 正文段落 | 逐段从下方渐入 | framer-motion stagger |
| 代码块 | 打字机效果 | CSS transition |
| 对比表行 | 悬停高亮 | CSS `:hover` |

**组件改造：**

- 工作流页改为 `'use client'`（或提取动效为独立客户端组件）
- 保持 Markdown 内容，但包裹动效容器

## 8. 项目列表页（/projects）

**当前状态：** 简单的链接列表，每个项目一条。

**目标设计（Sticky 卡片画廊——Awwwards 标志性效果）：**

```
滚动前:                    滚动中:
┌──────────────────┐      ┌──────────────────┐
│  📦 项目案例      │      │  📦 项目案例      │
│                  │      │                  │
│ ┌─ 卡片 1 ─────┐ │      │ ┌─ 卡片 1 (sticky)│ ← 固定在视口顶部
│ │ 🚀 项目一    │ │      │ │ 图片缩放 2→1  │
│ │ 用AI从零构建  │ │      │ └────────────────┘
│ │ ┌──────┐     │ │      │ ┌─ 卡片 2 ─────┐ │ ← 正在推上来
│ │ │图片  │     │ │      │ │ 🎨 项目二    │ │
│ │ └──────┘     │ │      │ │ 有创意的...  │ │
│ └──────────────┘ │      │ └──────────────┘ │
│                  │      │                  │
│ ┌─ 卡片 2 ─────┐ │      │   ...继续滚动...   │
│ │ 🎨 项目二    │ │      │                  │
│ └──────────────┘ │      │                  │
└──────────────────┘      └──────────────────┘
```

**动效清单：**

| 元素 | 动效 | 实现 |
| ------ | ------ | ------ |
| 卡片堆叠 | 每张卡片 `position: sticky; top: 10vh`，叠加 `margin-top` | CSS sticky |
| 卡片缩放 | 当前卡片从 1 缩放到 `targetScale`（0.95/0.90/0.85） | framer-motion `useTransform(progress, range, [1, targetScale])` |
| 卡片内图片 | 进入时从 scale(2) 缩放到 scale(1) | framer-motion `useTransform` |
| 卡片背景色 | 每张不同，形成彩色堆叠 | CSS 变量 |
| 卡片切换 | 平滑过渡，上一张缩小上移，下一张推入 | framer-motion |
| 项目标题 | 滚动到视口时从下方滑入 | framer-motion |

> **参考来源：** Razorpay Sprint 26 (Awwwards SOTD)、Olivier Larose Smooth Scroll Cards Parallax 教程

```
│  └──────┘ └──────┘ └──────┘          │
│                                        │
│  更多实验开发中...                       │
└────────────────────────────────────────┘
```

**初始方案：**

- 动画效果展示画廊
- 每张卡片展示不同的 CSS 动画（旋转、波浪、粒子文字等）
- 卡片进入视口时旋转入场

## 11. 通用交互组件

### 11.1 Nav 导航栏

**当前状态：** 静态导航，深色背景。

**目标设计：**

| 滚动位置 | Nav 外观 |
| --------- | --------- |
| 页面顶部 | **透明背景**，白色/深色文字（取决于下方内容） |
| 向下滚动 > 80px | **毛玻璃背景** `backdrop-filter: blur(12px)` + 底部 1px 边框 |
| 向上滚动 | 保持不变（已固定） |

**动效清单：**

| 元素 | 动效 |
| ------ | ------ |
| 背景过渡 | 透明 → 毛玻璃，500ms 过渡 |
| Logo | 悬停时微缩放 |
| 导航链接 | 底部指示线从中间展开（`::after` 伪元素 `scaleX(0→1)`） |
| 当前页链接 | 指示线常亮 |
| 移动端汉堡菜单 | 三横线 ↔ X 形变动画 |

### 11.2 Footer

**当前状态：** 一行文字。

**目标设计：**

```
┌────────────────────────────────────────┐
│  © 2026 · Built with Hki              │  ← 从下方渐入
│  [GitHub] [Twitter] [掘金] [知乎]      │  ← 磁力悬停图标
└────────────────────────────────────────┘
```

**动效清单：**

| 元素 | 动效 |
|------|------|
| 整体 | 滚动到视口时从下方渐入 |
| 社交图标 | 磁力悬停（跟随鼠标偏移） + 颜色变化 |

### 11.3 页面进出场过渡

使用 `framer-motion` 的 `AnimatePresence` 包裹 `layout.js` 中的 `children`。

```jsx
<AnimatePresence mode="wait">
  <motion.div
    key={pathname}
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0, transition: { duration: 0.4 } }}
    exit={{ opacity: 0, y: -10, transition: { duration: 0.2 } }}
  >
    {children}
  </motion.div>
</AnimatePresence>
```

### 11.4 平滑滚动（全站）

使用 `@studio-freight/lenis`：

```jsx
useEffect(() => {
  const lenis = new Lenis()
  function raf(time) {
    lenis.raf(time)
    requestAnimationFrame(raf)
  }
  requestAnimationFrame(raf)
}, [])
```

## 12. 新增依赖

```bash
npm install framer-motion @studio-freight/lenis gsap
```

| 包 | 用途 | 大小 |
| ---- | ------ | ------ |
| `framer-motion` | 声明式动画、滚动驱动、页面过渡、入场动效 | ~30KB gzip |
| `@studio-freight/lenis` | 平滑滚动 | ~5KB |
| `gsap` | 磁力按钮、高级时间线动画（可选，可用 framer-motion 替代） | ~15KB gzip |

> GSAP 主要用于磁力按钮效果。如果优先降低依赖，磁力效果也可用 framer-motion 的 `whileHover` + `onMouseMove` 实现，但 GSAP 的 `quickTo` 更简洁。
